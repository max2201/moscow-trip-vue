# Москва, 14–22 октября

Сайт для выбора жилья в Москве: предложения площадок бронирования, районы, места и события. Данные собирает `moscow-trip-pipeline`.

Лимит — **40 000 ₽ за все 8 ночей 14–22 октября 2026 для двоих**, дополнительно проверяется в `buildRows`, даже для объектов из плана. Полная сумма показана первой, сортировка цены использует её. Есть фильтр площадок и панель статусов: снимки, время цены, ошибки обновления, частичный охват и неподключённые источники.

По умолчанию видны все районы; иначе предложения новых площадок без района скрывались бы. «+/−» Островка остаются на прежних ID, у новых площадок свои ID. Неизвестная отмена отображается как «Уточнить условия». Рейтинги гостей нормализованы до 10; анализ отзывов для новых площадок не имитируется. При отсутствии координат расстояние площадки до центра подписывается отдельно и объект не рисуется на карте.

```sh
npm ci
npm run typecheck
npm test
npm run build
npm run dev
```

`public/data` — запасной снимок. При публикации GitHub Actions загружает свежий `site-data` из основной ветки pipeline. Ежедневный deploy запускается после обновления данных. Полный охват всех площадок не гарантирован; подробности статусов и реализованных сборщиков — в README pipeline.
